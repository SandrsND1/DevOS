### Проект: DevOS

DevOS — backend-система для управления разработкой программных проектов. Цель проекта — создать production-like приложение на C#/.NET с чистой архитектурой, PostgreSQL, Entity Framework Core, REST API и полноценным тестированием.

Основной стек:

* C# / .NET 10
* ASP.NET Core
* Clean Architecture
* Entity Framework Core
* PostgreSQL
* xUnit
* Moq
* Testcontainers
* Docker
* Git / GitHub

### Основная идея

DevOS должен позволять команде управлять проектами и рабочим временем разработчиков:

* создавать и редактировать проекты;
* получать информацию о проектах;
* удалять проекты;
* учитывать рабочее время;
* создавать Time Entries;
* связывать затраченное время с проектами;
* получать статистику по работе;
* в дальнейшем добавить пользователей и роли;
* предоставить всё это через REST API.

### Архитектурная цель

Проект строится по принципу разделения ответственности:

```text
DevOS
│
├── Domain
│   ├── Entities
│   ├── Value Objects
│   └── Domain Rules
│
├── Application
│   ├── Commands
│   ├── Queries
│   ├── Handlers
│   ├── DTOs
│   └── Interfaces
│
├── Infrastructure
│   ├── EF Core
│   ├── PostgreSQL
│   ├── Repositories
│   └── Persistence
│
└── API
    ├── Controllers
    ├── Middleware
    └── DI / Configuration
```

Главный принцип — **Domain не знает об Infrastructure**, а Application работает через абстракции.

### Цель разработки

Не просто сделать CRUD, а использовать проект как полноценную практику backend-разработки уровня Junior → Middle:

1. Clean Architecture.
2. SOLID.
3. Dependency Injection.
4. CQRS-подход.
5. Repository Pattern там, где он оправдан.
6. EF Core и PostgreSQL.
7. Unit Tests.
8. Integration Tests.
9. Testcontainers.
10. Docker.
11. REST API.
12. Validation и обработка ошибок.
13. CancellationToken и async/await.
14. Git/GitHub workflow.
15. Production-like структура проекта.

### Текущее состояние

Полностью реализована и протестирована бизнес-логика для `Projects`, `Tasks` и `TimeEntries`:
* REST API контроллеры (`ProjectsController`, `TasksController`, `TimeEntriesController`);
* Глобальная обработка ошибок (`GlobalExceptionHandler`);
* Команды, запросы, хэндлеры, валидаторы и DTO объектов;
* Entity Framework Core конфигурации, миграции и репозитории;
* Разграничение ответственности по Clean Architecture.

Сейчас:

```text
dotnet test

111 tests
111 passed
0 failed
(67 unit-тестов в Application.Tests, 44 интеграционных теста в Infrastructure.Tests)
```

Infrastructure-тесты используют реальные PostgreSQL-контейнеры через Testcontainers.

### Ближайшая цель

Реализовать модули аналитики, отчётов и аутентификации:
1. Аналитика и статистика затраченного времени (`Time & Project Analytics`).
2. Аутентификация пользователей и роли (JWT Auth, Users & Roles).
3. Docker Compose (`docker-compose.yml`) для полноценного развертывания системы.

### Главная долгосрочная цель

Получить **полноценный backend-проект, который можно показать работодателю как серьёзный pet-project**, демонстрирующий не только умение писать C#, но и понимание архитектуры, баз данных, тестирования, DI, Docker и production-подходов.
